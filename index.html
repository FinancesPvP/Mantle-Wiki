Mantle: ranks on top of LuckPerms

LuckPerms keeps your ranks and permissions. Mantle adds everything around selling and handing them out: store commands, grants with history, vouchers, sales, trials, a rank menu, and clean chat, tab and nametags.

Install

Requirements

WhatNeeded
ServerPaper, or a fork such as Purpur, 1.20.6 to 1.21.x, and 26.x. Spigot and Bukkit are not supported.
Java21 or newer. 26.x servers need Java 25.
Required pluginLuckPerms 5.4 or newer
OptionalPlaceholderAPI for placeholders. Vault plus an economy plugin, only for paid rank-ups.

Three steps

  1. Install. Put the Mantle jar in plugins/ next to LuckPerms and restart the server.
  2. Set up your ranks in plugins/Mantle/ranks.yml, or keep the examples, then run /mantle reload. If you already have LuckPerms groups, see Import existing ranks first.
  3. Check and apply. Run /mantle setup. If a group is missing in LuckPerms, /mantle setup apply creates it. The check also prints the store command to paste into your store.

The very first start needs to reach app.lukittu.com to check your license. See License.

Import existing ranks

Run this once:

/mantle setup import

Every LuckPerms group that isn't in ranks.yml yet is added with its prefix, weight and name colour, so it shows up in /ranks and the grant menu straight away. Groups that look like staff ranks are added as hidden.

Then add icons, perks and prices in ranks.yml and run /mantle reload.

Prefixes

A rank's prefix in ranks.yml is used for that rank. Groups not in ranks.yml, or with no prefix there, use their LuckPerms prefix. /mantle setup apply copies ranks.yml prefixes into LuckPerms so other plugins, like TAB or scoreboards, show the same thing.

Ranks

Each key in ranks.yml is a LuckPerms group. LuckPerms keeps who has which rank; ranks.yml adds the looks, perks, prices and rank-up rules. Only display is required.

SettingWhat it does
displayName shown in menus and messages
prefix / suffixShown around the name in chat, tab and nametags
colorColour of the player's name in chat and tab
weightHigher sorts first in tab and wins as the main rank
iconMenu item, any Material
descriptionLines under the name in menus
perksListed on the rank's page in /ranks
hiddentrue leaves it out of /ranks, for staff ranks
storeprice shows on the Buy button; link overrides the store link for this rank
rankupOnly for ranks on the rank-up path: cost, playtime, auto
rewardsConsole commands run when the rank is gained. Placeholders: <player> <rank> <duration>

Example

ranks:
  vip:
    display: "<gold><bold>VIP"
    prefix: "<gold><bold>VIP</bold> "
    color: "<yellow>"
    weight: 50
    icon: GOLD_INGOT
    description: ["Support the server."]
    perks: ["5 homes", "/fly in the lobby"]
    store: { price: "$9.99" }
    rewards: ["say <player> is now VIP!"]

Reward commands run straight away, so commands that need the player online (items, kits) only work if they are.

Store ranks

Add a command to your Tebex, CraftingStore or other store package, and set it to run when the player is offline too:

mantle give {username} vip 30d -a
FlagWhat it does
-aAnnounce to the whole network
-sDon't message the player
--from <buyer>A gift: "buyer gifted VIP to player!"
--no-rewardsSkip the rank's reward commands
--server <name>Give the rank on one server only
--reason <text>Reason in grant history (default "Store purchase"). Must be the last flag.

It works for players who are offline or have never joined, and every give shows up in /grants.

Times

Use 30d, 12h, 1w2d, 1mo or perm. Timed ranks stack: 30d on top of 10d left gives 40d.

Upgrades

mantle upgrade {username} vip mvp -a

Swaps VIP for MVP and keeps the time that was left. A permanent VIP becomes a permanent MVP. Add a time like 30d to set the length yourself.

Grants and history

/grant <player> opens a menu: pick the rank, length and reason, then confirm. You can also type it all out, from in-game or the console:

/grant Steve vip 30d Event winner

History

Every rank Mantle gives is recorded: store purchases, /grant, vouchers, trials and rank-ups. /grants <player> lists them with who gave them, when, why and when they end.

Removing an active grant asks for a reason and takes only that grant's time off the player's rank, or removes the rank if nothing else gives it. History is stored in LuckPerms, so it follows players across servers. Ranks given with plain LuckPerms commands aren't in it.

Who can grant what

mantle.grant.any grants every rank. Without it, give mantle.grant.rank.<rank> per rank, for example mantle.grant.rank.vip for helpers.

Single permissions and one-server grants

/grant Steve perm:essentials.fly 7d Event prize
/grant Steve vip 30d --server survival

Single permissions need mantle.grant.permission. List your server names in grants.servers in config.yml to get a server switch in the grant menu. grants.prompt-timeout sets how long the menu waits for staff to type a reason.

Vouchers, sales and trials

Vouchers

/mantle voucher vip 30d 5 Steve

Gives redeemable rank vouchers (rank, time, amount up to 64, player). Players right-click to redeem. If redeeming fails, the voucher is handed back. Vouchers for offline players are kept until they join. Item, glow and announcements are set under vouchers in config.yml.

Sales

/mantle sale 20 2d
/mantle sale stop

Runs a store-wide sale (up to 95% off) with a countdown boss bar. Change or turn off the bar under sales.boss-bar.

Trials

/ranktrial gives each player one free trial. Set the rank, length and minimum playtime under trial in config.yml.

Rank-up and prestige

For prison, skyblock and similar servers. Turn it on in config.yml:

rankup:
  enabled: true
  path: [default, member, elite]

Then give each rank on the path a rankup rule in ranks.yml: cost (money, needs Vault), playtime (like 2h), and auto: true to give it automatically once playtime is reached.

prestige.enabled: true adds /prestige at the top of the path, with a max level, cost, cost scaling, a prestige tag format and rewards.

Chat, tab and nametags

Chat

chat:
  format: "<chat-tag><prestige><prefix><player><suffix> <dark_gray>»</dark_gray> <gray><message>"

Hovering a name shows a card with rank, prestige and time left (chat.hover). Turn off chat.enabled if another chat plugin should format chat.

Tab

tab sets the name format, header and footer, and sorting by rank weight.

Nametags

nametags puts the rank prefix, suffix and colour above heads.

Join and quit messages

Set per rank under join-messages, with default as the fallback. "" hides a rank's message; mantle.join.silent hides one player's messages.

Tab sorting and nametags use scoreboard teams on the main scoreboard. If another plugin gives players their own scoreboard, turn off tab.sort-by-weight and nametags.enabled and let that plugin use Mantle's placeholders.

Cosmetics

/color, /chatcolor and /tags open menus set in cosmetics.yml. Each colour or tag unlocks with its rank (or higher), its own permission, or mantle.cosmetics.all:

mantle.namecolor.<id>
mantle.chatcolor.<id>
mantle.tag.<id>

Tags show where <chat-tag> is in chat.format.

Discord log

Set discord.enabled: true and paste a webhook URL into staff-webhook, and optionally public-webhook. Choose where each event goes in discord.events: purchases, grants, removals and more.

Keep webhook URLs private. Anyone with one can post in that channel.

PlaceholderAPI

With PlaceholderAPI installed, Mantle registers %mantle_<name>%. They read from Mantle's cache, so scoreboards and tab plugins can refresh them every tick at no cost.

Networks

Rank changes and Mantle's player data already sync through LuckPerms. To send announcements to every server as well, set messaging-service in each server's LuckPerms config, for example sql or redis. /mantle setup shows whether it's working.

Config files

FileWhat's in it
config.ymlTheme, store link, chat, tab, nametags, join messages, network, reminders, trials, grants, sales, vouchers, Discord, rank-up, prestige
ranks.ymlEach rank's look, perks, store price and reward commands
messages.ymlEvery message, so you can reword or translate the plugin
menus.ymlEvery menu: rows, slots, items, names and lore
cosmetics.ymlName colours, chat colours and tags

Missing settings are added to your files on startup with their comments. Nothing you changed is overwritten. A file with a mistake in it is copied to <name>.broken and Mantle tells you in the console, instead of loading example data.

Colours

Every text field takes MiniMessage (<red>, <#ff5555>, <gradient:#ffaa00:#ff5555>) or legacy codes (&c, &l, &#ff5555). <primary>, <accent> and <line> use the theme in config.yml.

Theme

theme:
  primary: "#8e44ad"
  accent: "#d070ff"
  tag: "Ranks"
  line: ""            # your own divider, or "" for the built-in one
  progress-bar:
    length: 10
    filled: "<accent>■"
    empty: "<dark_gray>■"

License

Your BuiltByBit download already contains your license key, so Mantle works straight away. You can also set it yourself in license.key in config.yml.

  • Mantle checks the key with Lukittu when the server starts and every 15 minutes after that.
  • It sends only the license key, the Mantle product ID and a random ID for that server folder.
  • If Lukittu can't be reached, Mantle keeps running for up to 24 hours after its last good check. After that it stops until the server can reach app.lukittu.com again, so allow it in your firewall.
  • Each license works on up to 2 servers.
  • A key that's been turned off, for example after a leak or a refund, stops Mantle with a message in the console.

Moved hosts and hit the limit? Message Deputy Dev with your BuiltByBit username.

Problems and support

Prefixes don't show in TAB or my scoreboard

Run /mantle setup apply to copy ranks.yml prefixes into LuckPerms, or use Mantle's placeholders.

Chat looks doubled or another plugin's format wins

Two plugins are formatting chat. Turn off chat.enabled in Mantle or turn off the other plugin's chat format.

Nametags or tab order flicker

Another plugin is setting its own scoreboard. Turn off nametags.enabled and tab.sort-by-weight.

Store reward items didn't arrive

Reward commands run straight away, so item commands only work if the player is online. Use a store command set to wait for the player for items.

My ranks disappeared after editing ranks.yml

The file has a mistake, usually indentation or a missing quote. Mantle saved a copy as ranks.yml.broken and printed the line in the console. Fix it and run /mantle reload.

Mantle stopped with a license message

See License. Most often the server can't reach app.lukittu.com.

Join the Deputy Services Discord (link on the BuiltByBit page) and open a ticket. Please include your Mantle version, server version and any console errors.
